# 固定腕Hand2初握筛查

此目录用于训练初态选择，不是保留集性能、教师轨迹或ego视频重定向结果。筛查标准先写入protocol，再运行全部候选；没有只保存通过者。

最终结果位于 `substeps_v2/`。原根目录的v1测量每20ms采样，完整保留；v2在相同阈值和全部候选上改为每5ms物理子步采样，避免漏掉控制采样间的接触峰值。

- 来源：官方单轴组10条clip，每0.5秒一个候选，要求后续有完整151帧/3秒。
- 范围：103个候选初态，各自测试零初速和源有限差分初速，共206次独立0.3秒hold。
- 控制：手腕固定、手指保持初始参考q目标、物体自由，t0之后不重写物体状态，无外加wrench、无reset。
- 标准：所有采样时刻位置变化不超过2cm、有向笔轴变化不超过20°；手物、自碰和其他contact穿透分别不超过3mm；关节与目标满足限位（1mrad容差）；不掉落、不接触非手支撑。初态需至少一个有效手物接触，但接触数量不作为稳定抓握证明。
- 可追溯性：所有候选、初始接触点/法向/接触指、每步hold状态、失败原因、代码/模型/源数据哈希与CPU耗时均保存。

v2有16次通过：源有限差分初速组9次，零初速组7次。按照预先规定的顺序，优先选择能兼容当前重置契约的源有限差分初速组，再按穿透、hold误差与固定ID排序。选中 `clip_009_f0250_source_fd`，对应原始clip_009第250至400帧（原5–8秒，stop-exclusive=401）。

选中候选的0.3秒CPU hold：最大手物穿透1.904mm，自碰与其他穿透0；位置最大变化3.967mm，有向轴最大变化14.09°。初始为食指接触，hold末为拇指与食指接触。它满足短hold筛查，后续3秒原运动仍未由该筛查证明可行，且还需在Warp后端验证。

可供后续实验使用的文件：

- `substeps_v2/selected_reference.npz` 与同名JSON：固定腕任务参考。
- `substeps_v2/selected_catalog/`：包含一个151帧的纯运动学裁剪clip，可用现有frame0加载器。
- `substeps_v2/selected_recipe.json`：训练/评估配方。
- `substeps_v2/provenance.json`：原clip SHA、原帧区间、派生clip SHA及任务重设计记录。
- `substeps_v2/scan.json`：全部206次结果，禁止用通过率冒充任务成功率。
- `substeps_v2/protocol.json`：执行前冻结的筛查标准。

原始视频父ID不可得，全部衍生项继续使用保守的整release split_group，不能把clip编号当作独立视频演示编号。裁剪本身没有生成物理教师或独立参考接触标签。

本筛查排序只回答初握能否短时保持，没有检查后续3秒是否包含足够转笔运动。容易保持的静止尾段不能替代转笔研究任务。正式转笔参考还应在所有通过初握的候选上施加独立、预先冻结的运动幅度/轴向一致性门槛；根目录选中的clip009因此保留为静态对照，不能直接称为转笔Demo。额外运动门槛与最终转笔候选的选择由研究主协议另行记录。

CPU成本分别记录在同级 `initial_grasp_scan_cost/`（v1）与 `initial_grasp_scan_substeps_cost/`（v2），GPU预留数均为0。v2进程总墙钟约7.00秒，包含Python导入、载入与记录；不能把它等同于训练成本。
