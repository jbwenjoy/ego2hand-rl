# Wuji Hand 2 × SuperMimic × CHORD：审阅修订与首轮研究执行

日期：2026-11-01。版本：v0.2。原方案：`C:\Users\ASUS\Documents\Codex\2026-10-31\qin\outputs\Wuji-Hand2-SuperMimic-CHORD-Demo-实施方案.md`。原文保持不变；本文件记录本轮修订。用户确认暂无指定 ego 数据，先做受控实验。本聊天已创建 active goal。

## 1. 审阅结论

原方案在“固定手型与物体，先验证受控参考修正，再检验共享成本”的范围内合理。SuperMimic 提供从仿真转移数据学习可微动力学并优化策略的机制；CHORD 提供物体目标与跨本体接触作用能力表征。它们能组合，但组合后的物理收益和总成本下降均是待检验假设。

需要纠正三项关键实现预期：

1. Dex 转笔现有15维 contact head 预测手指自碰撞，不是手笔接触，不能视为已有 CHORD 接触表征。
2. 训练日志 `task/rot_error` 对笔读取兼容字段中的单位旋转，不是参考笔姿态；笔的端点奖励只约束轴向，不含轴向 roll。最终评估须独立计算。
3. pen PPO 尚未实现；FailureHead 的真实与想象特征时序不一致，DR context 也不完整。首轮隔离这些因素：无 FailureHead、固定物理参数、关闭外部扰动、观测噪声与动作冻结；不把问题混入接触消融。

精确定位见 [SuperMimic 审阅](supermimic-audit.md) 与 [CHORD 审阅](contact-audit.md)。

补充：`contact_weight` 控制自碰预测的监督损失，不是手物接触奖励开关。pipeline smoke可设0；正式A1保留上游0.1监督，自碰头与新增CHORD手物头分开。否则想象奖励仍读取被关闭监督的自碰头（当前零初始化使其为常数），不能称为完整native-objective对照。

## 2. “无本体 ego 数据”的范围

这里指演示没有目标机器人的本体状态和动作标签，不等于部署策略可以没有机器人观测。训练可使用仿真真值；部署输入仍需来自关节反馈、物体跟踪或另训的估计器。

完整链路需要：ego RGB/时间与相机标定 → 人手/物体/尺度/场景重建及不确定性 → 机器人运动学重定向 → 可达性/固定腕筛选 → 参考与接触目标 → 仿真动力学 grounding → 自由物体完整片段验证。RGB 不直接给出真实接触力、质量、摩擦或机器人反事实转移；物理参数应记录测量/假设来源。

首轮上游 NPZ 属于机器人运动学参考。它不包含视频、重建置信度或独立接触标签，因此只能回答受控轨迹修正问题。NVIDIA 仓库的 `tissue_box_simple` 是真实 ego 派生参考候选，但原始 MP4 未公开，本地二进制最初只是 LFS pointer；其两种机器人表示来自同一个演示，不能计为两条独立视频。该搬运片段也未证明适合固定腕。

本轮下载后确认 NPZ 还包含 `mediapipe_landmarks_w` 人手关键点，可供后续隐藏机器人关节标签的运动学重定向受控试验。其原始视频谱系和相机信息未建立，不能据此认定为独立ego数据。已校验10条单轴clip：时长6.32–9.16秒，完整源腕角变化13.84–37.20°；0/10通过5mm/5°近固定腕筛选。子片段仍可另筛选，当前默认3秒实验明确记录为任务重设计。

一般参考不能通过逐帧腕坐标消除来保持动力学。源腕移动被删去时，惯性与重力关系发生改变。必须保留原腕轨迹，先做腕位移/旋转和机器人可达性筛选；不满足时标记为固定腕任务重设计，或留待带机械臂版本。

## 3. 可检验假设与门槛

| 假设 | 对照 | 能支持的结论 |
|---|---|---|
| H1：残差优化能修复小范围运动学偏差 | A0直接参考 vs A1 SuperMimic | 受控任务的物理执行质量改善 |
| H2：独立阶段接触目标有额外收益 | A1 vs A2，同预算、同非接触设置 | 接触目标的因果贡献与失败模式 |
| H3：共享模型/策略降低新增轨迹成本 | 独立训练、共享模型、共享模型+策略、共享model-free策略 | 相同质量门槛下的总成本及边际成本变化 |
| H4：作用于无机器人标签的 ego 演示 | 独立原始演示保留集，完整感知与重定向管线 | 真实数据适用边界；本轮尚无此结论 |

H1/H2 成立前不启动大规模多轨迹训练。单条短训练只验链路。研究结论至少3种子，按完整原始演示划分；同源切片、扰动副本、不同本体输出留在同一 split。

## 4. 实现契约

数据采用 `supermimic_chord_reference:1`：SI、右手世界系、wxyz；20个关节名与角度、时间、笔与腕位姿、阶段、质量/惯量/半径、来源类别和原始演示分组。物体坐标原点与 COM 偏置、资产哈希、源腕与固定腕变换、重定向算法和置信度均保存在 provenance。接触点/法向独立来源，unknown 与已知无接触分开。

姿态度量用 `orientation_metric=directed_axis_x` 或 `SO3` 显式定义。上游笔轴任务忽略轴向roll是任务等价关系，不是物体精确轴对称的声明；250mm资产两端有方形标记几何，其roll仍可能影响接触动力学。完整SO(3)误差保留为诊断。

真实执行与想象必须共享 `reference + EMA(clamp(residual)) - encoder_bias` 契约，并保存实际目标、EMA、动作历史、限幅/冻结、延迟、负载积分、时间相位。若增加限幅或物理上下文，应作为独立变更重新验证。

接触 support 使用物体系点和朝物体内的作用方向；单位摩擦锥 `[f,(p×f)/r]` 在固定单位六维方向集上求非负最大值。半径只缩放力矩一次。support 是几何能力表征，不是真实力/力矩估计，不含执行器能力，不能证明牛顿—欧拉可行性。阶段需区分保持、旋转、释放/换指；单纯增加接触可能损害转笔。

真实 MuJoCo 接触用于监督和最终评估。想象奖励使用独立预测或几何代理时，需先测接触识别、切换误差、support 预测、短期状态误差及梯度方向；模型虚构接触的高回报反例必须保留。单步 MSE 或函数可微均不构成梯度可靠性证据。

## 5. 阶段交付与停止条件

| 阶段 | 本轮产物 | 完成门槛 |
|---|---|---|
| M0 | 两份源码审阅、数据/控制契约、实验协议 | 问题有源码定位；来源和假设可追溯 |
| M1 | Hand2独立Windows环境、方块/笔模型、短训练/保存恢复 | CUDA与物理状态有限，日志/版本/命令可复跑；未达此门槛不报任务学习 |
| M2 | 单条固定腕上游参考、A0与A1、独立完整物理评估 | 无VOC、无逐帧对象写入、无RSI/重置；源参考未验证前不称teacher |
| M3 | support数值对齐、手笔接触与想象代理、A1/A2同预算 | 仿真轨迹和接触梯度均有独立证据；无收益也属于有效结论 |
| M4 | 1/5/10/20原始轨迹成本曲线及保留轨迹 | 计入教师/预训练/编译/评估/重试；无泄漏且同质量门槛 |
| M5 | 真机子版本、控制标定和物体观测闭环 | 确认硬件后单独执行；本轮不自动控制实物 |

首轮配置在 `configs/controlled-study.json`。建议筛选值：位置2cm、有向笔轴20°、穿透3mm、腕位移5mm/旋转5°；这些是工具起始值，不是既有表现或最终验收标准。先根据250mm笔、测量噪声和动作目标审定，再冻结于正式比较之前。

若3–5秒片段的A0完全失控，应先核查初始抓握、模型与坐标，或生成经物理验证的教师，不盲目扩大训练。若想象建议方向频繁恶化真实物理目标，先补接触/失败数据和控制状态，再做A2。
