## State target validity

`native_state58` (lines 18–45) constructs a lightweight object containing CPU copies of the recorded full `qpos/qvel`, explicitly addressed robot joints and object free joint, and a fixed palm transform. Line 43 executes **the original `SimReader.state` method**, rather than implementing an approximation. The original method at [sim.py:95](D:/workspace/dex-supermimic-research/src/dex_supermimic/rl/dex_supermimic/sim.py:95) packs `q20, qd20, p3, R9, v3, omega3`. The actual recorded mappings in the proof are robot qpos 7–26, dof 6–25, position actuator 0–19; they are verified rather than assumed by the codec.

Object free-joint angular velocity is body-frame. The original method converts it through the **same poststate's** object rotation, then the inverse palm rotation. The first three object velocity components are world linear velocity, rotated only into palm coordinates. Body COM offset is required to be zero. The proof's nontrivial object/palm rotation distinguishes this operation from treating body omega as world omega; it does not just test identity rotations. Object quaternion normalization is native behavior; the codec first rejects norm errors greater than `1e-5`, and the actual recording is FP32. The existing proof reports a maximum FP32/native versus independent FP64 arithmetic discrepancy of `2.861022953659642e-6`, within its componentwise roundoff bound. This is an arithmetic comparison, not a physical error tolerance.

The verified MJB is `24fd7bf2658e1a6795e636eff1f1bc0a6f65f14baf4ed88a85dd2ffe125c33dd`. The prior independent static model review records base body 3/mocap 0 and palm body 4/mocap **-1**. The palm is not itself asserted to be a mocap body. The original reader refreshes its entity root-link frame; the palm-rooted source/identity-child relationship makes the fixed frame binding valid for this asset. This is not a general mocap-to-palm rule.
