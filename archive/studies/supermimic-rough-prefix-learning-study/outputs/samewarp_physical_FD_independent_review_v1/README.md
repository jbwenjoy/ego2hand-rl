## Blocking issues in v1 and their corrections

1. **The strict WM loader cannot load after CUDA initialization in the same process.** The actual [world_model_checkpoint_v2.py](D:/workspace/supermimic-rough-prefix-learning-study/src/rough_prefix/world_model_checkpoint_v2.py:65) rejects that state. The correction's default route is sound: GPU worker saves fresh donor state58/u/xi, native labels and physical branches, terminates/releases GPU, then a fresh CPU-only process strict-loads all three104 WMs. Do not bypass the loader guard. Physical branches remain model-independent, so this ordering does not change branch selection.
2. **Four logical resets are not four startup forward calls.** [Manager.reset](D:/workspace/dex-supermimic-research/.venv/Lib/site-packages/mjlab/envs/manager_based_rl_env.py:358) calls forward; the rough reset wrapper additionally calls [_restore_initial_state](D:/workspace/supermimic-rough-prefix-learning-study/src/rough_prefix/runtime_v2.py:91), which calls forward. Four paths require at least eight reset-related forwards. Constructor/graph warmup forwards need a separate measured count. The corrected limits of 2,480 integrating substeps and 620 postinterval forwards remain mathematically consistent. This is a lifecycle/cost correction, not an extra physical intervention.

The correction also appropriately withdraws any assumption that post-forward lazy sensor data are automatically fresh. The authoritative self15/torque labels are the original pre-forward reward capture.

## Snapshot, capacity and phase contract

[WarpTaskSnapshot](D:/workspace/dex-supermimic-research/src/dex_supermimic/rl/dex_supermimic/snapshot.py:6) copies whitelisted reachable Warp arrays, Torch tensors, Python containers and RNG states. Its walker does not traverse function closures, clone arbitrary NumPy arrays, or recursively support arbitrary `rough_prefix` classes. The proposal correctly requires explicit inventoried sidecars for controller/action/observation caches, PEN memory, pending flags, phase/counters and identities. Exact integration roundtrip alone cannot prove complete state restoration. No added forward may hide a failed restore.

Installed [`mujoco_warp.support.get_state/set_state`](D:/workspace/dex-supermimic-research/.venv/Lib/site-packages/mujoco_warp/_src/support.py:667) transfer integration channels including qacc warmstart, controls, applied forces, mocap, equality activation, userdata and history. They exclude derived/contact/sensor/overflow buffers. `set_state(INTEGRATION)` itself does not clear overflow; a full snapshot restore can rewind the copied overflow array. Therefore the host OR ledger must be outside the snapshot traversal and must read before **every** full restore, after every branch, at donor termination before any restore, and finally before close. Any unknown/nonzero flag invalidates engineering; final sticky zero alone is insufficient. Actual allocation/max counts must be measured without inferring world attribution from a flag array's shape.

Fresh snapshots are taken before processing phase k, after the preceding original native Manager forward/command/sense/observation sequence. Each branch restores the same complete state, processes the same recorded raw action once, then changes only the absolute executed target cache. It holds that target through the original four substeps and original scene updates. It does not alter q/qvel/object pose, apply external support, replace controller EMA with a clamped-target reconstruction, or reproject/clamp perturbations. The original policy probe's nominal baseline+EMA assertion must not be reused unchanged for deliberate target interventions: a new observer must separately prove the nominal source action/EMA update and the actual overridden target at all four substeps.

Physical objective uses fixed current-reference phase k as primary, with k+1 tracking separately retained. State x1 reads post-integration q/qvel at kdt+20 ms. [PenSimReader.attach_capture](D:/workspace/dex-supermimic-research/src/dex_supermimic/rl/dex_supermimic/pen.py:351) obtains native self15/torque from the final just-completed solver at approximately kdt+15 ms, before the final Manager forward. Original `scene.update` cache invalidation is part of that cadence. Raw contact type/geom/efc associations must be captured from the actual Warp buffers; converted host contacts or positive-force filtering must not stand in for the original sensor's CONSTRAINT-filtered `found` semantics.

The 15 labels are 10 finger link2/link3 found flags plus five link4-or-tip flags against the palm subtree. New native captures can provide these actual self15 labels; the old archived raw labels remain UNKNOWN. They are not hand-object labels or force estimates. Binary contact has no continuous physical derivative here. Before implementation freeze, designate fresh-donor capture as the nominal label and save all three baseline label vectors/consistency separately; do not select a majority/lucky label or infer calibration quality from an all-negative set.

## Replay tolerances and valid interpretation

The chosen q/p/R-entry `2e-5`, qd/v/omega `2e-4` and unscaled reward `2e-5` gates are declared adoptions of old serial-probe numbers. They are not a demonstrated accuracy/convergence certificate for current104. New full-array/memory/RNG/control byte identity is explicitly stronger; clock `2e-6 s` comes from the current timeline contract. The primary fresh baseline comparison is to the newly captured donor next state. Three baselines are required; none may be selected because it agrees better.

Archive state drift is a separate reproduction flag, while initialization/context/nominal executed-u identity is required. It must not replace prior physical grades, or silently compare a WM evaluated at archived x against physical FD from a different fresh x. The legacy stable-nonflat rule retains both epsilon signal thresholds, baseline noise, matching signs and slope agreement. Flat/unstable/omitted cases stay in planned denominators; no threshold or epsilon adjustment follows results. No suggested policy-step/improvement branch is included in this experiment.
