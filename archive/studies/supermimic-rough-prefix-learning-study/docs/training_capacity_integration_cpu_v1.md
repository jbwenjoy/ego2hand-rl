# Training integration, CPU evidence

`rough_prefix.training.run_training(config, bundle, output, emit)` calls frozen `native_v2.run_native`. It accepts `engineering_smoke` and `primary_matched` roles with A1L/P_ONLY/A2; accepting a role is not execution authorization. Native A0 is excluded. No previously executed source was changed.

An outer Manager constructor scope installs the frozen capacity observer immediately after native environment construction, before Runner construction and its first reset. Each reset first reads and latches the real sticky field. Before Env.close, the observer makes its one final read and writes `capacity_observation.json`. Nonzero flags or UNKNOWN fail engineering qualification. The original body exception survives a secondary cleanup UNKNOWN; class and instance hooks restore in finally.

Format104 checkpoint serialization adds `rough_capacity_evidence` after the controller and native runtime evidence layers. Its actual observation event is `checkpoint`; it neither clears flags nor finalizes the observer. `prefix_at_checkpoint_capacity_qualified=true` describes only the saved prefix, while `entire_run_finalized=false` and the original `engineering_capacity_qualified=false` remain explicit. The final run snapshot separately requires its final read. Non104 saves pass through with their original payload.

The Runner constructor scope saves `initial_parameter_tensors.pt` after the original constructor returns and before collect or optimizer updates. `modules[name]` contains ordered `parameter_names`, CPU-cloned `parameters`, `shapes`, and `dtypes`, plus capture-point and source pins. This permits independent reconstruction of the later native initialization fingerprints and parameter deltas. It does not independently reconstruct seed-based model initialization.

The [35-check CPU receipt](../outputs/training_capacity_cpu_v1/report.json) covers reset-before-clear, checkpoint/final separation, payload preservation, no added RNG changes, UNKNOWN/overflow rejection, original-exception preservation, and scope cleanup. It also exercises the actual DexSuperMimicRunner.save atomic temp/replace method and frozen rough-controller serializer, with a narrow replica of the RecordedRunner runtime-evidence layer. Manager/backend and Runner initialization are fixtures. No actual Env, physics, optimizer, CUDA or training was run. Executed source snapshots are preserved in that receipt directory.
