# Frozen WorldModel CPU consumer

Use `rough_prefix.world_model_checkpoint_v2.load_world_model_checkpoint(checkpoint, bundle, expected_method, training_run, health_report)`. It returns a frozen evaluation Module and a JSON receipt. `wrapper(x58, u20)` accepts finite FP32 CPU tensors and returns native next-state58 and self-collision logits15. It does not apply a controller, EMA, C2 or control clipping. Input control autograd remains available; model parameters and normalization remain frozen.

The loader reuses the original format104 Actor consumer's root/controller/reference/init/velocity/source/MJB verification, then requires the selected actual final2000 file, frozen v3 health, original training configuration and run directory. The physical context is independently loaded from the pinned bundle. `reader_context` is exactly128×46 and matches the frozen source bitwise in every row. Task/critic context368 is a separate quantity. The WM input is native `cat(state58, xi46, zero174)` with total dynamics278, then actual control20; native delta52/contact15/hidden512×3 load strictly with CPU AMP disabled.

The [55-check report](../outputs/world_model_checkpoint_cpu_v2/report.json) includes actual A1L/P_ONLY/A2 final checkpoint loads. Each actual WM received one synthetic valid-rotation state and one forward/control-gradient calculation. Inputs, complete state_dict and host normalization counts, RNG, checkpoint bytes and context files stayed unchanged. The fixture gradient is a software autograd diagnostic; it is not a measured physical Jacobian, dynamics-accuracy test, hand-object force/contact predictor, or GPU AMP parity result. Raw-state encoding and prediction error evaluation are separate work.

The first loader source and [failed v1 report](../outputs/world_model_checkpoint_cpu_v1/report.json) are retained. It rejected before any WM construction/forward because it incorrectly required every actual8 field to have128 storage rows. Native Warp model fields may store shared parameters in one row. V2 accepts one shared row or128 rows with exact shape/value broadcasting; physical xi still requires128 per-world rows. No training checkpoint, physical parameter or previously executed source was changed.
