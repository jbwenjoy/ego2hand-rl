# 105 serial probe implementation interface

This is source preparation. No Env, model, physics, restored branch, Actor/WM forward or GPU has been executed by this implementation task. Root owns all device authorization and lifecycle supervision.

`full151_gradient.serial_probe105_v1.run_probe(bundle, config, out, emit)` accepts the already validated full151 bundle. The output directory is the fresh, Root-owned worker directory; the front may already have archived config/source/runtime files there. Episode artifacts must not exist. The implementation lazily imports the installed simulator only in `run_probe`. `validate_config(config, bundle=None)`, `execution_plan(mode)` and `allocate_artifacts()` are CPU metadata/NumPy operations.

The config schema is `full151105_same_warp_physical_probe_run:1`, role `full151105_serial_physical_probe`. It uses `evaluation_seed:0`, `probe_mode:engineering_restore_smoke|serial_full`, `GPU_run_authorized` boolean, `training_authorized:false`, `automatic_retry:false`, `compile_fallback:false`, soft180/hard240, proposal/protocol/input_bundle pins, flat source_pins, and `foreign_inventory_review:null|pin`. Root adds `_worker_started_perf` before calling the API. No model or checkpoint is loaded by this producer.

`donor_inputs` has exactly `A0` and `A2`. Each item has an absolute `directory` and `input_pins` containing exactly these basenames: `controller_descriptor.json`, `control_events.json`, `raw_states.npz`, `evaluation.json`, `config.json`, `fixed_physics_context.npz`, `native_reward_transitions.json`. Each pin is `{path,sha256}` and must resolve to that basename under the directory. A2's archived config checkpoint must equal the proposal's fixed A2 final2000 checkpoint. A0 events lack actions; zero is explicitly declared. A2 saved clamped actions are replayed. These are fresh action-source donors, not closed-loop Actor runs or archive-state reproduction. Archive drift is reported separately and cannot change the selected states or old scores.

Initial `foreign_inventory_review:null` is deliberate discovery.
