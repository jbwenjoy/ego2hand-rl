# Saved-source five-slot cues

`observation_potential_five_cues.npz` contains151×5 source-rigid slots at landmarks3,7,11,15,19, with finger IDs1..5. It is schema `full151_source_potential_five_cues:1`, a separate artifact from the old three-slot cue, H123 support targets and objective bindings.

The CPU producer ran once and passed18/18 checks. It opened only explicitly selected time, source-hand-point, source-object-pose/confidence, mapping R/t/pose and saved all21 surface members. It reconstructed source→mapped→object BODY frame relations, checked object transforms, and extracted stored closest points, outward normals, feature IDs, tie masks/counts and axis ambiguity. It did not execute the surface function, read robot q/FK/contact answers, or inspect policy contacts, forces or quality. Every field shared with the old H123 cue has identical first-three-slot values and dtype, including non-slot time/pose/R/t fields. The old source and output files are unchanged.

`geometry_valid_mask` is a numeric/unambiguous-geometry mask. `declared_potential_mask` is separately allTrue under the fixed potential H12345 experiment; it is not human contact truth or a support-shaping target. Actual data have151 valid geometry rows for each of the five slots. Synthetic boundary cases retain an invalid/tied slot as unknown while its potential membership remains true. No proximity cutoff, zero imputation, release annotation or alternate landmark was introduced.

`object_surface_closest_body_m` is in object BODY coordinates and has not had COM subtracted. A downstream wrench consumer must subtract its source-bound static COM once and negate `object_surface_outward_normal_body` once for force-on-object inward normals. It must not treat outward normals as contact-force observations. Human contact/confidence-known masks remain allFalse, human unknown remains allTrue, and stored human-presentFalse is only a placeholder under UNKNOWN.

The intended downstream302-LP experiment is separate. Its H123 control selects the first three slots from this same five-slot source. Missing geometry must cause UNKNOWN for that full declared set; infeasibility of an available subset cannot certify full-set infeasibility. No LP, native geometry query, Env, FK, physics, Actor/WM, optimizer or GPU ran here. No512 support target, A2 objective or training readiness is generated or inherited.
