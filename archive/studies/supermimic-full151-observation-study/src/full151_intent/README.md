The specification is schema `full151_declared_H123_objective_spec:1`; the actual validated example is `outputs/full151_intent_binding_CPU_v2/objective_spec.json`.

`binding.py` is the preserved first attempt. Its canonical constructor reached the saved32 forward/backward stage, but `PenaltyOnlyPrior` then failed because the new metadata omitted the frozen wrapper's `scoring` field. Its source, pre-execution snapshots, specification and `failure.json` remain in `outputs/full151_intent_binding_CPU_v1`. Do not treat it as the active factory or silently alias it to v2. The strict new constructor calls `nn.Module.__init__`, bypassing the legacy kinematic-reference manifest constructor.
