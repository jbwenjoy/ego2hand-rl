# Prefix16 保存数据的约束失败审阅

该候选保持了固定的 q0 和所有 16 个关节位置节点的硬限位，但没有取得下一步物理试验所需的几何资格。16 帧中 12 帧的已生成手物接触深度超过冻结的 3 mm 门槛。`ftol` 成功结束表示目标函数变化足够小，并不表示碰撞、速度或动力学约束通过。本审阅只读取既有 candidate、native contacts 和 report；没有再次查询碰撞、优化或运行物理。

## 可复核的主要结果

- 最深重叠在 frame 5 / 0.10 s：`object/cube` 与 `robot/right_finger1_tip_sensor_col`，深度 **5.141163 mm**。同一几何对有两个等深接触，均保留。该拇指末端几何对在 frame 4–15 全部超过 3 mm。食指末端传感器几何另在 frame 14–15 超过 3 mm，峰值 3.048868 mm。
- 最深帧的 F1/F2/F3 材料点误差分别为 **0.997221 / 1.979121 / 0.007632 mm**；法向误差为 **59.0817 / 54.5725 / 15.3817°**；骨方向平均角误差为 **16.4037°**。材料点靠近目标不能保证整根手指，尤其末端碰撞体，不与物体重叠。此前冻结的 F1 材料绑定是 link4；本次最深重叠是其末端传感器几何，并非同一个表面点。
- 目标函数总 cost 为 224.711397：重叠项占 **60.53%**，材料位置占 **29.68%**，骨方向占 **9.35%**，法向占 **0.433%**。相邻与二阶关节差分合计仅占 **0.000632%**。这是一组量纲和残差定义下的实际代价分配，不是各语义目标的重要性排序。
- 原始保存 Jacobian 上，重叠项与材料位置项在 frame 5、15 的局部梯度余弦分别为 **−0.8363 / −0.9972**，显示当前选择的局部分支存在明显方向冲突。该分析没有重新验证碰撞导数；15 帧存在接触等深 tie，共 26 个已生成 pair/frame 槽位。不能把这项局部代数分析称为全域有效的碰撞梯度证明。
- 优化器用 46 次函数 / 37 次 Jacobian 评估，以 `ftol` 条件停止；记录 optimality 为 1.465669。成功标志是该停止规则的结果，不能替代硬不等式可行性检查。

全 16 帧表在 [all_frames.csv](D:/workspace/supermimic-observation-prefix-study/outputs/prefix16_failure_review_v1/all_frames.csv)，逐对原始记录、残差代价、tie 和保存梯度分析在 [report.json](D:/workspace/supermimic-observation-prefix-study/outputs/prefix16_failure_review_v1/report.json)。未生成接触的距离仍为 NaN；手自碰未生成接触不等价于取得了正间隙证书。

## 为什么固定 q0 和时间软项仍不足

当前损失中的 `.03 * Δq` 和 `.03 * Δ²q` 没有除以 dt 或 dt²，属于有限的平滑偏好，不能保证速度、加速度或控制速率上界。保存节点的最大 `|Δq| / .02` 为 **21.636038 rad/s**，位于 frame 13→14 的 `right_finger1_joint3`。这里 q 是几何目标，既有三个输入没有实际 u、C2 或 PD 阻尼补偿的时序，故不能将这个数直接当作已测实际 target-rate 失败。

q0 的 joint index 3 距下限仅 2.22e−16 rad。按已规定的端点二阶差分，其初始设计导数为 −8.6566e−7 rad/s，方向朝外。这是需要连续曲线范围验证的边界信号，不是可以通过替换差分模板、把初速强设零或裁剪 q0 消除的检查。节点本身合法，也不能保证节点之间的插值范围、几何间隙或速度合法。

材料法向残差是 `.25 * (n − n_goal)`，不是角度阈值。每个单位法向的 cost 等于 `.0625 * (1 − cos θ)`，最大仅 .125；毫米归一化的位置和碰撞残差可远大于此。因此材料点位置被拟合时，法向仍可有几十度误差。整个骨方向项也使用单位方向差，并非硬角度约束。固定手材料和 object-local 表面点贯穿 16 帧，还隐含了持续同一材料接触、不滑移的意图假设；观测没有提供已知接触标签来确认该假设。

## 下一版约束设计的具体审阅意见

1. **先分开可行性和拟合质量。** 保持冻结的 3 mm 资格门槛；若下一版采用显式不等式或分层可行性阶段，必须单独报告可行 / 不可行 / 求解未证实。当前重叠代价已经最大，不能仅凭这一失败把方案简化为增加软权重。
2. **规划间隙必须与固定 q0 一致。** 当前 q0 已有 2.183021 mm 深度，故将所有帧改为硬 0.5 mm 上界会直接与固定初态矛盾。0.5 mm 是本版软 allowance，3 mm 是资格门槛；两者不能互换。任何新的规划裕量或初态变更都应另立协议，而不能回改本结果。
3. **独立约束连续关节范围、设计速度和真实控制。** 后续需要检查选定曲线的全区间极值、边界导数、u 的 C2 映射、实际 target-rate、PD 阻尼及初态 q/qd/u 的一致性。它们不能由原始关节差分软损失或一次静态预载见证继承。
4. **硬碰撞接口需要处理未激活几何对和非光滑分支。** 原生碰撞列表在未生成接触时不提供正间隙；NaN 不可填零。使用硬碰撞不等式之前，需要明确有效的间隙/接触发现接口、等深 tie 规则和分支变化的导数资格；不能假定换更严的 CCD 参数就获得更准确的距离。
5. **整手几何约束与接触意图分开。** 单点吸引不能代替末端和其他碰撞几何的非穿透约束。持续贴附、滑动、滚动或释放属于不同且置信度未知的接触模式假设；未来若声明替代模式，应保留当前失败，预先固定新模式和选择规则，不能在线重选最近点并把它称为接触标签。

本结果否定的是该软目标和本次局部求解对这组冻结假设取得资格，不能证明原动作不可行。Prefix16 是完整运动方案的初始化阶段；不得把旧 151 帧的 q 尾段接上去，也不能把此前 frame0 静止持有的正结果转移成动态跟踪资格。本轮没有执行替代优化或物理试验。
