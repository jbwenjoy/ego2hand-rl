Status: CPU data ABI demonstrated; reset/control/replay/training integration remains pending. No training, optimizer, physical run or old-source modification is authorized by this proposal.

The minimal route uses the **existing native reader**, with one separately enrolled rough reference and a runtime adapter in a new training entry. It does not extend or bypass the current shared-ten registry. The observation identity is the legacy fixture's source range **[200,216)**; its native local reference range is **[0,16)**. The variant is `H123_cubic_minimax_restoration_filtered_prefix16_v1`. Neither local indexing nor the source clip number makes this the shared catalog's clip007 **[0,151)**.

It does not rename macro landmarks or read source robot labels as goals.

Artifacts are in [restored_prefix_native_ABI_v1](D:/workspace/supermimic-observation-restoration-prefix-study/outputs/restored_prefix_native_ABI_v1/native_catalog_manifest.json). They are not extra unsupported recipe keys.

The real CPU reader completed and its loaded arrays were saved. The original adapter then failed its last JSON receipt write on a NumPy boolean; this original process failure and source are retained. The separate [saved-only finalization review](D:/workspace/supermimic-observation-restoration-prefix-study/outputs/finalization_review_v1/report.json) passes **20/20** reconstructed checks without rerunning FK or the reader. q32 and native FD errors are zero; relative object position/rotation errors are 3.56e-8 m / 3.30e-7, BODY21 local error 3.95e-8 m. This is a usable CPU data-ABI artifact, not a clean original terminal-receipt PASS or a demonstrated training interface.

## Required data/reset contract

The descriptor must bind observation/parent identity, raw [200,216), local [0,16), variant, candidate/source-plan/protocol SHAs, the four-key native artifact/recipe, model and actual context, original BODY/joint order, analytic init bundle, 15-command baseline schedule, C2 source/margin, and mode. Keep source data, goals, designed initial states, actual reset readback, residual history and actual executed u separate.

The saved **analytic qd0 differs from native reader FD0 by up to 11.938072 rad/s**. For finger3 joint3 the analytic value is 16.055521 and native FD is 4.117449 rad/s. Do not overwrite a field under the same name or silently reuse reader FD for initialization. Native goal FD remains available for audit; the startup qd/body-origin world velocity and native-body angular velocity come from the explicitly frozen init bundle. With the existing entity world-state writer, supply world angular velocity once and independently check the raw freejoint body-angular readback against `R(q32).T @ omega_world`; do not apply that conversion twice. Preserve q0 without projection, default wrist/mocap, actual8, zero exogenous inputs and exact selected u0.

Each reset must finish this installation before `Runner.__init__`/first collect refreshes state, memory, actor observation or normalization. Partial reset must touch only the selected environments. Reject random-frame/adaptive RSI and first-frame holds for this prefix until they have their own per-phase initialization contract. The proposed first pilot is phase0-only.

Root's recommended controller baseline is the frozen **u_baseline15 + EMA residual**, in real and imagined paths, with reward/observation q goals remaining the derived native q reference. EMA c1/c2 start at their true residual history (zero); never encode u0−q0 as prior action history. See [the independent training-interface review](D:/workspace/supermimic-observation-restoration-prefix-study/outputs/rough_reference_learning_integration_review_v1/report.json) for controller/WM/gradient details. ## Fifteen intervals, replay and unknown targets

There are 16 reference knots but **15 control intervals**. Native `reference_end` checks `time_steps+1 >= length` before command advancement; after a forced phase0 reset it would execute an extra interval at phase15 unless explicitly adapted. The new real/imagined short-horizon contract must terminate after interval14 produces state15, preserve that terminal transition, expose obs/reference15, and never request a sixteenth target u15. Do not pad a new command or clamp continuing phase15 into an apparently valid training transition. Imagined dead-row handling belongs to the matching controller/WM contract, not the data exporter.

[shared_reference/replay_metadata.py](D:/workspace/supermimic-shared-reference-study/src/shared_reference/replay_metadata.py) provides a useful metadata/mask contract but is not installed in native replay. The new entry must preserve the equivalent checks: episode boundary, prefix/start/end, phase increment, raw source frame=200+local phase, actual u distinct from q goal, terminal row retained and reset suffix masked. Source/variant IDs remain metadata rather than new network features. An environment holdout is not a heldout trajectory; no009/010 exposure may enter train collection, normalizers, WM fitting or imagination starts under a train8 label.

[TargetRegistry](D:/workspace/supermimic-shared-reference-study/src/shared_reference/target_registry.py) currently has ten missing target bundles and validates exact native artifact/window before lookup. It must continue to fail closed. Neither old clip007 [0,151) targets nor the historical controlled [200,351) target bundle can supervise this new q16 by truncation. A1L may declare no contact-prior module; P_ONLY/A2 must use a separately frozen new-prefix objective/geometry-intent binding if their current factory requires it. Unknown contact intention/force observations remain unknown, never fabricated zero support or known absence. A fixed geometric hypothesis is not a physical hand-object label.

## Explicit rough-reference research mode

Proposed new mode: `rough_reference_pilot`. It intentionally permits learning against a **physically unqualified** derived reference after the new data/reset/control/replay engineering gates and separate Root authorization. It does not bypass the old shared registry's `require_training_ready`, set `physical_reference_qualified=true`, relabel failed H0/T0 tracking as success, or claim validated ego/force supervision. Online simulator states/forces are training measurements; the q/object/BODY reference remains a rough kinematic target. Full physical evaluation remains independent and retains all failures.

Before any engineering training smoke: actual native-reader data binding; real reset fullq/fullqd/twist/mocap/u0 readback and partial-reset parity; real/imag baseline target/EMA/WM-u parity; exact 15-interval real and imagined terminal traces; replay provenance/mask negatives; and a checkpoint descriptor that rejects old reference/controller/init identities. The format number and finite budgets remain for Root's next frozen plan. No old103 checkpoint is silently converted or treated as an exact resume. Dataset preparation, the failed metadata attempt, setup, evaluation, training and any later target generation are separately charged.
