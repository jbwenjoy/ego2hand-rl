## 局部线性反馈的基准

在两个名义解的每一帧，围绕实际运行状态做关节和自由杯切空间、速度及 PD 命令的成对扰动，建立共同名义模型的 52 维状态与 20 维控制雅可比；超出执行器限幅的探针使用实际可发送的弦长。使用有限时域 Riccati 递推计算反馈增益。混合模型复用原生状态雅可比和手部控制响应，只将物体位姿和速度的 12 行控制响应替换为已冻结的共享网络估计。两种增益均只在名义参数生成。另设手指关节 PD、五指尖雅可比运动学校正、直接重放三个基准。所有反馈的逐关节额外目标限制为 ±0.08 rad。名义条件五组实际 PD、手和杯的端点均与已存路径逐元素一致。[局部扰动与增益](../runs/mug_nominal_tracking_gains_v1/report.json)

在 11 个非名义条件上，原生线性反馈相对冻结指令的配对时长中位数在 001884、001888 分别为 −0.38、−0.08 秒；混合线性模型分别为 −0.34、−0.14 秒。在各相位留出的四个小幅动作方向上，原生雅可比预测平移响应的误差与零响应误差之比分别为 0.45、0.62，混合模型为 0.89、0.86。结果提示有限差分与学习头都需要单独核对跨接触切换的局部有效范围。[完整的 120 次原生对照](../runs/mug_tracking_feedback_v1/report.json)

## 两步滚动校正

在每个 20 ms 控制窗，用当前实测状态构造 12 个残差，包括原指令、保留部分上个残差、手指运动学校正、时变线性反馈和六个相同种子生成的扰动。每个候选在私有 MuJoCo 模型中推进两个控制窗，第二窗按 0.8 衰减残差，执行第一步后重新计算。筛选优先通过原始参考的全部六个门限，再比较相对于已通过的示范的杯子质心、完整旋转、手指状态和命令偏离。扳手项以权重 0.2 比较候选与名义示范在对应控制窗的净接触扳手，依据源杯体坐标下的动量变化构造；人体视频未提供接触力。各候选使用零求解器热启动，未读取被测对象的实际质量或摩擦。另运行一个已知执行模型参数的诊断组。状态与名义完全一致时沿用原指令。[规划记录及 60 次复测](../runs/mug_witness_mpc_v1/report.json)

在九个预先选定的非名义条件上，001884 的位姿、位姿加扳手两组相对开环的配对时长中位差分别为 −0.02、+0.02 秒，001888 分别为 +0.08、+0.16 秒。两个控制器在 001888 的初始杯沿自身 x 轴偏移 −1 mm 时均完整通过 0.92 秒，冻结指令为 0.38 秒。知道真实参数的扳手控制器还在 001888 的轻杯和高摩擦两种条件完整通过，其他条件下仍有失败。名义正确的参数本身不足以保证短时排序能维持整条轨迹。[源视频与同一偏移下的开环、闭环重放](../runs/mug_feedback_video_v1/offset_feedback.mp4)

## 计算与验收

实现 Windows 本地 C 辅助库，使用现有 MuJoCo DLL 进行 64 次积分并就地读取接触数组和关节边界。编译器和头文件、运行时 DLL 的身份独立记录；使用前核对 ABI 版本和浮点数宽度。五指与杯的穿透、手自穿透、关节越界和桌面法向力沿用 Python 审计口径。两段成功路径、违规路径和显式桌面接触诊断上逐控制比对六项指标、广义坐标、速度、暖启动和已发送的 PD 命令均完全一致。名义成功轨迹中，单窗口实测从约 10.1–10.6 降至 8.2–8.5 ms；该数值是整段原生步进与审计的时间。候选间用独立数据并行后，12 项规划的数值复验在两个先前扰动条件及名义条件重现原串行 CPU 决策与全部已执行状态。实时预算仍需把感知、测量、控制通信和抖动一并计入。[构建与哈希](../runs/mug_window_native_v2/report.json) · [等价性与计时](../runs/mug_window_native_check_v1/report.json)

下一阶段的主要证据缺口是新参与者或新物体上的反馈效果，以及共享策略能否在持握型参考和运动型参考中同时保留收益。两段名义示范、成功的扰动恢复和失败条件都可用于训练；训练时应保留冻结指令作为候选，并分开衡量接触参数变化与起始位姿变化。
