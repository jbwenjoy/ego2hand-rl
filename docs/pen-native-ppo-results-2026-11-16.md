# 第一轮实际原生PPO短训练与严格转笔评测

本轮实际训练了策略，不是仅拟合WM。32环境、32次迭代、65536条训练
transition、1024次PPO优化更新完成；首2次和最终检查点健康均10/10，独立
完整加载/固定rollout CUDA更新核对均20/20。完整285项测试通过。该结果是
原生model-free诊断基线，尚未证明SuperMimic/CHORD收益或真实ego泛化。

本批训练后均值策略的原生终止推迟到约1.14–1.18秒，初始化/第2次检查点
均约0.14秒，但原7.36秒任务仍全部失败。尤其32次策略从7.5ms起已超过原
2mm物体穿透门槛，不能把“持续更久”称为合格转笔或符合全部接触动力学要求。

## 训练、终止采集和保存恢复

使用独立tag的policy161/critic188、原固定腕/资产/50Hz/dt2.5ms，原始高斯
sample与执行前[-1,1]裁剪值分开存，保持0.5 scale/0.5 EMA/原PD边界。
PPO复用共同更新函数，没有修改旧cube-only配置限制或把155维权重改当161。
actor/critic为FP32；AdamW lr1e-4、weight_decay0、gamma.996/GAE.95/clip.2、
4epochs×8minibatches，每次2048条rollout完整整除，无丢样本。

每个rollout及相应更新期间冻结观测归一化，在下一rollout开始时用上一批
原始观测更新统计，避免“采集log_prob与优化时归一化不同”。先另采8控制步
零raw的全新TRAIN归一化数据，再在训练起点重置全部环境，计256条/2048积分；
没有使用先前DIAGNOSTIC_NEVER_FIT数据或检查点训练。初始归一化288样本，
首2次后2336，最终63776。仅低层Normal调试参数检查在采集内关闭，block-end
有限/无外力/容量检查保留；旧cube调用默认行为不变，未宣称性能已全面修复。

采集在重置前保存真实terminal-next policy/critic/value，timeout只加一次
gamma*V(terminal-next)，真正终止不bootstrap，GAE不跨重置。混合边界手算
测试通过；实际32环境8控制步及独立1环境末参考帧pre-start夹具共2056积分、
40/40项核对通过，包含真实reference_end的truncated和返回phase369后重置1。
末帧夹具是另一个预启动状态诊断，不是原始任务成功或训练数据。

新的训练检查点组合网络、优化器、norm、上一rollout/归一化批、计数/RNG
和native portable schema3。新schema增加参考数组内容摘要、history/delay
排除规则保护以及784个标量值读回；795数组字段仍逐字节一致。未来32环境
物理轨迹非重复性仍未验收，不能用序列化成功抹去该失败。

首2次保存后停止该阶段进程，完成独立加载/ETA检查，再从该检查点以新进程
完成剩余30次。首轮审阅14/18的克隆比较失败：Adam CPU step张量在审阅器的
两份优化器间共享，第二份起点已被第一份改变。已将source/live/clone副本
隔离，新增不可变测试；20/20重审通过，失败v1的64次克隆更新与原记录保留。
首2次与最终各另有64次成功克隆更新；合计192次丢弃的诊断优化步骤，均未
改变保存的训练策略或发生新物理积分。没有隐藏这些额外计算。

## 严格原任务结果

评测使用新鲜原phase0物理初态、各自保存的actor/norm和高斯均值动作，
没有从训练末状态续跑、warmup动作或post-start重置/外力辅助。原始RMS/max、
完整SO(3)、穿透/自碰撞/关节/非手接触、时长、finite/capacity门槛全部保留。
参考是同一条训练clip，完美位姿，无相机/ego泛化。三组动力学数组与训练
检查点逐位匹配；独立原始EFC/接触/位姿读回99/99通过，正确重现失败门槛。
