## Decision

Deleting improvement-only termination helps this shared SHAM source but is
insufficient and increases iteration-cap frequency. Do not deploy/admit this
candidate for training, recollect a training corpus under it, raise iteration
limits, relax physical thresholds or rerun full54 as if the backend were fixed.

Next inspect the pinned line-search/incremental-update source against these
saved endpoint scalars. Determine the smallest missing observation needed to
distinguish cost/bracket precision, exhausted search and rebuild behavior; make
any later native trace a separately registered bounded experiment. The current
1,920-integration budget is closed. Do not infer a precision root cause from
alpha0 alone. Preserve true A1/A2, reference feasibility, independent references/
seeds, full-task benefits, GPU performance, ego asset/gravity/dynamics/RGB and
hardware observation/control/gains/latency requirements in the main plan.
