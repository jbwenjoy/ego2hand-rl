# 桌面接触力和求解器收敛校准

HO-Cap 纸盒的 FlashCHORD 训练场景把桌面表示为带自由关节的运动学刚体。编译后的平均惯量约为 **1.58 × 10⁹**。MuJoCo 的迭代停止准则按惯量尺度归一化。在这个场景中，默认设置会在接触力仍与加速度矛盾时结束迭代。以 150 g 纸盒为例，重力约 1.47 N。因此旧配置下的轨迹、奖励、吞吐与短训练可用于排查软件和数值问题，正式成本比较需要在经过校准的物理配置上重新开始。[MuJoCo 关于求解器 tolerance 的说明](https://mujoco.readthedocs.io/en/stable/XMLreference.html#option-tolerance) · [旧训练停止及检查点记录](../runs/wuji_flashsac_matched_v1/obsolete_physics.json)

## 交叉检验

在相同纸盒、Wuji 手和源动作前 15 帧中，分别用原运动学盒体、原生静止平面表示桌面，再交换二者的编译惯量尺度。两种桌面在此段接触处的上表面都是世界 z=0。四组执行同一串上层手部指令，各自运行 600 个物理子步。取 MuJoCo-Warp 的广义加速度与已报告的力，在单独的 float64 MuJoCo 数据中重建质量矩阵，核对纸盒平移三自由度上的 **M(q)·qacc − qfrc_smooth − qfrc_constraint**。这项检查计入质心偏移导致的平移和转动耦合，也适用于加速中的物体。

| 桌面 | 用于停止判定的平均惯量 | 迭代次数中位数 | 三轴力平衡残差均值 | 末五帧桌面对纸盒的平均竖直支撑 |
| --- | ---: | ---: | ---: | ---: |
| 原生静止平面 | 0.0790 | 2 | 0.00061 N | 1.471 N |
| 原运动学盒体 | 1.58 × 10⁹ | 1 | 42.30 N | 22.741 N |
| 原运动学盒体，使用平面场景的惯量尺度 | 0.0790 | 3 | 0.00095 N | 1.474 N |
| 原生静止平面，使用异常大的惯量尺度 | 1.58 × 10⁹ | 1 | 523.49 N | 1.472 N |

四组在末五帧均无手盒接触。第四组虽然在末段给出接近物重的数值，全程残差仍很大。只检查静止末帧会漏掉碰撞瞬间的错误。这个交叉试验在 WSL 的 CPU 后端执行。它隔离了停止尺度的影响，不能据此推算修正后 5090 的训练吞吐。[独立交叉试验与原始数组](../runs/wuji_table_causal_cpu_v1/report.json)

## 对训练和评测的影响

早期 GPU 短训练已保存检查点，也确实完成了优化器更新。正式对照启动后发现该问题，旧配置在首个完整检查点（31,296 环境步）停止，保留实际花费。纸盒此前的 141 帧合格导出在另一套原生 MuJoCo 场景中独立积分验证。[原生 MuJoCo 全段重放](hocap-carton-first-source-replay.md)

校准后的配置保留原桌面和碰撞拓扑。在初始化时，仅从惯量统计中剔除运动学桌面的六个自由度，按可动部分质量矩阵的对角线计算平均值。三个开发物体分别通过了 CPU 和 5090 上的静置与 5 cm 落桌检查。G04_2 的 CUDA 实测中，静置支撑为 0.9999 倍物重，落桌后为 1.0040 倍，力平衡残差 RMS 分别为 0.00016 N 和 0.00023 N。来自手部动作的 46 帧轨迹上，CPU / CUDA 的竖直力平衡残差 RMS 约为 0.0018 / 0.0016 N。该校准限于已检查的固定质量、单刚体场景。[校准设置和各物体的实测数值](../configs/flashchord_wuji_physics_v2.json) · [动态 CUDA 核验](../runs/flashchord_conditioned_dynamic_cuda46_v1/report.json)

新训练从第零步重新开始时，应共同使用此版本并重新测量吞吐。原数值一致性指标继续报告。GPU 相同控制的状态差别另做物理复验，两次独立初始化的重放须各自通过原有位姿、接触、穿透、关节与完整时长要求。独立状态误差和物理复验结果分别保存。
