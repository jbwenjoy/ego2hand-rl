# 六模型RAW奖励梯度：数值自洽，原生真实性仍不足

冻结六个最终2000更新模型、原数据/奖励/控制器后，完成单步RAW链路
分析，58/58检查通过。V1分析18.620秒，导出修正后的V2重复分析另计。
全套516项测试通过，包含闭式手部
奖励导数与直接RAW代价、缺失梯度/空组和零响应分母。无新物理积分、
优化、归一化拟合或Actor更新；没有按本轮分数选择模型或修改损失。

逐条核验全部4860实际RAW动作及36个源控制上下文。实测BASE_R0中心
TRAIN20/24、验证10/12，其余源仍保留不可用/裁剪状态，没有制造梯度。
使用记录的实际PD作为模型输入基值，链式导数为PD偏导*.25+直接RAW
动作惩罚偏导，源状态和EMA在这一个20ms窗口固定；未加值修正/直通
估计，不代表多步EMA梯度。所有基值PD再次与控制器精确一致，模型
权重/缓冲均未改变。数组保留两种偏导、增益、最终RAW梯度及源顺序。

全部1440个声明组/67个原物理失败行仍保留。TRAIN779/验证386个物理
合格对用于全量汇总；可观测/完整原生目标分别固定自己的原生双幅度/
双重复稳定屏，不能把它们混用。每个PD-eps为.002/.005，对应RAW-eps
.008/.020，中央有限差分分母为8*PD-eps。

六模型的自动微分与各自有限差分，在全部96个队列/目标/分量/子集
汇总上的相对差为5.77e-5–1.82e-3。这是模型内部数值自洽；下面与原生
响应的偏差仍明显。单位为原奖励，无尺度拟合；零响应相对L2=1。

“可观测”仅含末状态跟踪/显式动作代价和平均扳手bonus；“完整”列
将同一个模型proxy导数与含区间几何的原生有限奖励响应比较，不代表
模型已提供完整奖励。没有补成一个常数几何头、使用未来真值或只保留
好方向。Fn6头不是当前bonus的直接输入，Fn6响应改善不能替代此检查。

响应监督两组在稳定子集上优于点预测，但全量验证仍接近零响应基线；
加入Fn6监督的两组在这些验证指标上反而劣于零响应。TRAIN中的响应
两组可观测稳定误差约0.31–0.38，验证约0.61–0.81，需保留这个差距。
这些是同一已查看参考/固定演员训练种子下的开发诊断，不是ego或独立
未见参考泛化结论，也不能据此否定其他CHORD/共享模型设计。

验证源SUPPORT_N8861_P066的BASE_R0原冲量行门失败，32个其他物理
合格对涉及这个中心。所有误差分母保留这32对并显式记录无效中心；
候选局部准入不计它们。全量/稳定子集的基态有效数量分别报告，没有

完整稳定残差误差0.998仍有136/280候选；候选数不能替代精度或收益。
