# 纸盒控制器的物理子步敏感性

在 G04_2 开发纸盒已通过验收的 30 rad/s 限速指令上，保持原始 141 帧参考、腕指目标、控制增益、桌面、质量和接触材料固定。每个外层控制区间为 1/30 秒。原低层控制律仍在每个物理子步根据实际腕状态生成反馈力，并插值手指位置目标，因此变更子步数也会改变这套低层反馈律的数值采样频率。把每个变体的时间步改回原值，序列化的 MuJoCo 模型与原文件哈希完全相同。[原始限速轨迹及验收](../runs/hocap_carton_peak_slew_v1/phase_evaluation.json) · [比较代码](../tools/check_hocap_carton_substeps.py)

40 子步的实际状态、每子步手指和腕指令、以及验收指标均逐值重现原记录。80 子步与 40 子步的纸盒轨迹相差 0.69 mm / 0.47° RMS，全程最大差为 2.95 mm / 1.96°。20 子步时最大盒体碰撞穿透达到 3.14 mm，抓取阶段没有形成足够的承重。每个档位的实际指令均在重新加载的模型中从头执行，重放状态误差为零。[三档的数值与逐阶段记录](../runs/hocap_peak_slew_substeps_v1/summary.json)

计时为一个低优先级原生 CPU 进程的三次串行重复，轮换档位顺序，包含控制、积分及逐子步接触记录，排除模型加载、压缩文件写入与单独的验收。该片段支持将 40 子步作为已验证配置，80 子步可作为更细的交叉检查。20 子步虽然更快，但改变了已冻结控制器的物理结果，现有证据不足以把它计为同等质量下的加速。正式 GPU 训练及其他物体是否呈现同样的敏感性，不能由这一次原生回放外推。
