# HOT3D mug articulated control, 2026-11-20

The existing 61 annotated frames (47–107 in HOT3D Aria clip 1884, right hand) describe five canonical fingertips in the mug BODY frame. The previous 101-sample fixed-wrist control input used a constant mechanically selected grasp. Here the robot's initial fingertip sites supply five offsets in BODY. Each target adds the annotated human fingertip's displacement from its first BODY location, interpolated with the archived original timing, and transforms the result through the anchored mug pose. This defines a relative-motion target; absolute human and robot finger positions can differ.

All 101 bounded 20-joint IK poses were obtained with a warm start and penalties relative to the initial grasp and previous solution. Five-tip positional RMS against the engineered target decreased from 5.606 mm (constant joints) to 0.0063 mm. The maximum finite-difference joint speed was 5.74 rad/s; hardware velocity, latency and real force compatibility remain open.

Using the same calibrated-in-model joint transmission, nominal mug mass/inertia/friction, start and preload for both arms, CPU MuJoCo ran 6,400 unassisted steps per arm. At 50 Hz the new arm commands the next target posture plus original preload. No servo targets saturated. Actual fingertip RMS improved from 17.98 to 16.32 mm, but the 10 mm mug COM deviation first occurred at 0.30 s with articulation and 0.36 s with the constant grasp. Two-second COM RMS was 426 and 449 mm respectively and includes loss of holding and subsequent table interaction. COM errors were independently recomputed from saved post-step free joint positions and local COM to within 3e-16 m.

The separate instantaneous hand-only friction-pyramid screen found solutions for the nominal interval mean wrench on 3/97 articulated reference intervals versus 1/97 constant-grasp intervals. Only one in each arm also kept hand/mug penetration within 0.1 mm. Two articulated frame-level solver statuses were unresolved for at least one tested wrench. Force rays use source-frame hand contact, nominal gravity and no actuator bounds. An LP solution and tiny fingertip RMS do not certify sustained grasp.
