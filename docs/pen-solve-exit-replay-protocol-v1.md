This implements the ten-condition observation protocol without changing its
120-query/960-native total cap, A/B fresh processes, three numerical repeats,
original masks, settings or absence of updates. CPU registration may precede
closure. Actual execution must first pass the implemented terminal full54 and
final V3 ownership check, before any simulator imports or output directory.

Every declared condition appears in each repeat/scope. Rotate condition order
within each teacher by repeat/process ordinal and alternate scope order.
Restore each original complete native4/Python/RNG source before EACH query;
verify full readback and unchanged external counters. Recreate LIVE features
and the same backend/runtime/config. Use the recorded float32 RAW20 and require
the actual PD sequence to match its original record. No Actor/normalizer is
loaded or updated. Preserve original-case identity and transport separately
from the new current-software source capture; never relabel an old snapshot.

Historical full54/native4 source records do not contain a separately saved
policy161 observation vector. Consequently, the worker can verify full owned
state restoration, reconstructed input102 bytes/PD/reward, and equality of newly
regenerated policy/critic observations across restored scopes/repeats. It cannot
directly compare to an unavailable historical policy vector. This explicitly
refines the earlier phrase "original observation"; do not fabricate that proof.
Recorded RAW controls do not depend on regenerated policy observations.

Per teacher, build the observed graph from a restored declared source. Preserve
before/after full state and RNG captures, native clocks, external native counter
and observer counter; require graph construction to leave native/Python/RNG
bytes unchanged and marker count zero. Record capture API calls/time separately.
If capture unexpectedly advances the native clock, report its inferred tick
count as additional setup work, stop before queries and preserve the failure;
an ambiguous clock change has unknown setup integration count, never zero.

Every real Simulation.step is counted externally as attempted/completed before
the recorder returns, never rewound by source restore. The observer marker is
an additional execution witness, not the budget counter. Baseline must add0
copy events; observed scope exactly1 per native step and8 per query. Save every
raw packet/window/source/end as usual, every solve-exit copy, regenerated
observations, complete restore audits and all timing/count metadata. Preserve
partial recorder bytes when a query fails. No native retry/resume after failure.

For observed queries, require all eight epochs and aligned qpos/qvel/qacc/
constraint/applied-force/time fields before inferring forces. Recompute original
raw/EFC decoding and original impulse residual. Use the actual source packed

Record terminal OR predicates, component vectors/signed projections and every
original/new physical mask. Nonfinite/misaligned copies remain failures, not
rows quietly removed from a qualified dataset. No engine fix or physical label

Report byte equality and max absolute differences for ALL raw trace fields
between scopes and against the original record, separately by condition/repeat.
Observer differences and failure non-reproduction are outcomes, not causes to
select a favorable repetition. Both processes must finish independently and
receive saved-data review before aggregating the bounded diagnostic.
All graph/setup/restore/query/audit/storage wall costs count; no speed claim.

same480-native per-process cap; there is no extra unreported smoke budget.
