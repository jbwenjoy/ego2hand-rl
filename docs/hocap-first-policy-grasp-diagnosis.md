# 首轮纸盒策略为何错过抓取

在与正式实验相同的 Wuji、纸盒、桌面及修正求解器配置上，独立 CPU 诊断复用了首轮检查点已记录的动作。诊断没有重新训练或重评正式分数。

同帧画面把这次失败定位在抓取阶段。在第 46 帧，人手已把盒子抬高 113.5 mm，逐条离线修正轨迹抬高 108.4 mm，而学习策略的盒子仍由桌面支撑。后续学习策略状态因终止而缺失，视频在此处结束。[原片、首轮策略与离线修正对照](../runs/hocap_subject1_learned_native_visual_v1/comparison/source_learned_and_offline.mp4)

独立复算已记录的接触对显示，第 36–46 帧的 440 个物理子步中，成功轨迹的拇指与至少一个其他手指在每个子步同时承载，接触法向夹角超过 120°。手部平均竖直承重为 1.143 倍物重；桌面承担 0.002 倍。首轮三种学习策略在相同窗口内均无超过 0.01 N 的手盒接触，桌面约承担一倍物重。数据分别来自原生 MuJoCo 和校准后的 Newton/MuJoCo-Warp，因此用于对照动作和受力阶段，两套积分的轨迹不作数值等价比较。[成功轨迹受力](../runs/hocap_grasp_acquisition_comparison_v1/native_verified.json) · [三组学习策略受力](../runs/hocap_grasp_acquisition_comparison_v1/learned_verified.json)

将策略实际关节状态重建到碰撞网格后，全部手部刚体的位置与原记录在 0.00023 mm 内吻合。用纸盒凸包的支撑平面和指垫包围体计算保守的分离距离下界，第 26–35 帧中，单条、多参考无模型、混合方法的拇指距盒体分别至少为 27.0、18.5、21.4 mm。这个下界可以证明相离，数值为零时不能证明真实接触。[几何间隙与腕指交叉替换](../runs/hocap_grasp_acquisition_comparison_v1/gaps_certified_r1/report.json)

## 碰撞对

官方求解器编译后，全部 21 个手部碰撞体均允许与 G04_2 的实际纸盒碰撞体接触。在已知可行的原生抓姿上，按同一世界坐标恢复手腕、各指与自由物体，初速度设为零，并执行 12 个物理子步。对第 30、38、45、65 帧，超过 0.01 N 的手盒载荷分别出现于 10、12、11、11 个子步。前 3 个姿态分别有 3、3、1 个子步出现拇指和其他手指同时承载且接触法向点积低于 −0.5。第 65 帧将手沿世界 X 平移 300 mm 后，12 个子步均无手盒接触。官方物体碰撞网格与原生凸包在 1,030 个方向上的最大支撑距离差为 0.0214 mm。这些检查使用受控姿态初始化，验证碰撞通路能产生载荷，未检验策略从首帧建立持续抓取的能力。[逐碰撞对、法向与载荷](../runs/hocap_wuji_pair_probe_cpu_v2/report.json) · [纸盒几何](../runs/hocap_wuji_pair_probe_cpu_v2/carton_geometry_comparison.json)

## 腕平移残差的配对干预

从首帧开始，在同一个 CPU 求解器配置上重放各方法已有的动作，另做一遍只将动作中的三个腕平移残差设为零。每组的腕旋转目标、20 个手指目标及目标速度缓冲在两个条件下逐帧完全相同。源物体、重力、控制周期、驱动力与摩擦等条件相同。所有结果都止于第 46 个物理区间。

| 首轮已记录动作 | 原样重放的腕位置 RMS，f26–35 | 去掉平移残差后的腕 RMS | 有载荷子步，原样 → 去残差，f26–46 | 去残差后对置拇指子步 |
| --- | ---: | ---: | ---: | ---: |
| 单条 FlashSAC | 76.34 mm | 3.86 mm | 0 → 167 / 840 | 0 |
| 多参考无模型 | 47.04 mm | 3.91 mm | 0 → 70 / 840 | 0 |
| 多参考加世界模型 | 52.04 mm | 3.82 mm | 0 → 249 / 840 | 0 |

以单条动作为例，f26–35 的实际腕目标相对当前源帧分别偏移约 +72.7、−25.1、+5.7 mm，腕部实际位置相对于已发命令的平均偏差只有 −1.3、+0.3、−3.5 mm。三个轴在该窗口均未触及驱动力上限。源帧采样与下一帧边界计分贡献的平均差约为 0.0、−0.8、+0.1 mm。给全零残差加入有界源腕线速度前馈，腕跟踪 RMS 从 3.79 mm 降至 3.30 mm，仍未拿起物体。在这段动作里，平移残差使手离开能够接触纸盒的区域。消除该偏移能恢复部分触碰，仍缺少持续对置夹持。此处使用同一组已存动作作反事实开环干预，无法据此推断训练一个限制平移的新闭环策略会有多少提升。[直接 IK 与速度前馈试验](../runs/hocap_wuji_wrist_acquisition_cpu_v1/report.json) · [单条配对](../runs/wuji_wrist_translation_ablation_single0_v1/report.json) · [共享无模型配对](../runs/wuji_wrist_translation_ablation_shared_mf_v1/report.json) · [混合配对](../runs/wuji_wrist_translation_ablation_shared_wm_v1/report.json)

## 训练时是否见过动作后半段

三个首轮检查点的回放缓冲区都含主纸盒动作的全部 141 个参考编号。单条策略当时保留 131,072 条记录，其中 76,000 条起始参考相位在后半段；共享无模型与混合方法各保留 43,648 条该纸盒记录，后半段分别为 30,725、30,270 条。这些记录中的实际物体辅助尺度均大于零。随机重置可以抵达后半段，而从首帧关闭辅助重放时仍需自己建立初始夹持。这里统计的是已保存缓冲区里的 n 步起始观测，不能据此推断整次训练的累计访问量、真实人手受力或首次无辅助成功时间。[按参考、相位及辅助量核对的计数](../runs/hocap_grasp_acquisition_comparison_v1/replay_coverage_r1.json)

混合组累计提交 1,009,152 个环境步后，训练辅助的目标已降到零。其缓冲区中仍有 43,648 条主纸盒记录，21,016 条实际辅助为零。在这些无辅助记录里，仅 59 条观察到手盒接触方向信号。只看第 26–35 帧，也只有 25/3,264 条无辅助记录有该信号。同期首帧评测分别走到 25/140、77/220、39/275 个区间，三次均提前终止。训练中看过源轨迹的每个阶段，但缓冲区为“无人为支撑时已经接触”的状态留下的样本很少。[第二轮缓冲区抽查](../runs/hocap_grasp_acquisition_comparison_v1/replay_coverage_hybrid_r2.json) · [实际评分与中断计费区间](../runs/wuji_flashsac_matched_v2/round2_hybrid_cost.json)

将该轮真实学习器内的世界模型冻结，用另行采集的开发纸盒无辅助转移验证。从 1,692 个不跨重置的三步窗口来看，模型对纸盒位置预测 RMS 为 23.51 mm，保持当前位置的对照为 24.55 mm；姿态 RMS 分别为 10.46° 与 10.24°。其中 695 个接触状态切换窗口的位置 RMS 为 30.74 mm，对照为 32.33 mm。这些结果反映实际策略训练所得模型在该分布上的短期误差，仍不足以证明通过其反向传播得到的动作梯度可靠。[冻结世界模型的逐类验证](../runs/hocap_grasp_acquisition_comparison_v1/saved_model_validation_r2.json)

## 固定的指垫预载能否移到另外两件物体

在另外两条开发示范上，保持各自的原始腕轨迹、自由物体、150 g 名义质量和平桌设置，使用同一套源手指到扫描表面的 IK 修正。虚拟预载为 0 时两段均未抬起。使用主纸盒试过的 10 mm 指令预载，Pocky 盒仅抬起 35.7 mm（源动作 227.8 mm），衣物柔顺片盒仍未抬起（源动作 207.1 mm）。四个条件均未通过完整验收。此试验只移植指令先验，没有把主纸盒逐条拟合的腕部动作带入其他片段，也没有使用真实留出集。[Pocky 盒](../runs/hocap_dev_pad_prior_transfer_v1/subject3_pad10/evaluation.json) · [柔顺片盒](../runs/hocap_dev_pad_prior_transfer_v1/subject4_pad10/evaluation.json)
