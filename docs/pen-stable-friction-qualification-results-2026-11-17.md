# 稳定摩擦代价后端：实现与未通过的 GPU 资格检查

结论：独立代价后端、工厂绑定、运行时身份和异常恢复已经实现；**三个版本均未通过原定 GPU 字节保持检查，尚未准入动力学对照或训练**。这一轮没有新策略效果视频。目标保持进行中，M0–M5、真实 A1/A2、真实 ego、硬件契约与性能验证等范围不变。

## 实现与不变量

新实现在共享 `src/supermimic_research/runtime/` 下；没有另建研究仓库、修改安装包、驱动或 CUDA。原版 `_solve_done` 的 OR 停止条件、50 次迭代限制和物理参数均保留。候选只包装 pyramidal 单步长和三步长辅助函数的摩擦代价返回；AST 检查要求导数/Hessian、非摩擦分支和线搜索算法不变。明确的新执行身份包含碰撞后端、安装源码、代价辅助函数、生成工厂、绑定和状态导入适配器的文件身份。

同一区间的代价差使用稳定公式。令 `s=alpha*jv`、`j=Jaref`、`r=f/D`，二次区间为 `s*(D*j+0.5*D*s)`，两侧线性区间分别为 `-f*s` 和 `f*s`；跨区间仍使用原表达式。V1 使用 FP32 新中间量；V2 使用独立 FP64 代价中间量并返回 FP32；V3 进一步在回退时直接返回原向量。V2/V3 保留原 FP32 导数计算，没有改质量、摩擦参数、参考、动作、奖励或原 `5e-7 Ns` 物理门槛。

工厂隔离需要同时处理两层缓存：上游工厂缓存按参数和函数名索引，Warp 的 unique 模块还会按内核内容复用。新实现复制原缓存装饰器的 AST 到模块内私有缓存，并为外层工厂建立明确的路径所有者名称；没有清除或修改旧缓存。检查实际 kernel 的 Python globals、闭包中的单/三步长辅助函数和原 alpha-zero 函数归属。CPython marshal v2 用于稳定比较代码，避免嵌套 Warp 编译后的引用/驻留标志改变被误判为代码修改。

`CostProfile` 只声明 W1、nv26、dense incremental Newton/pyramidal 域；W32 显式拒绝。历史状态只增加既有 `termination_backend` 元数据字段，该字段现在携带明确的代价后端 schema，并注明停止条件未变。完整数值/Python/RNG 状态和类型化树摘要仍须按原契约核验。实际图捕获和原生状态恢复尚未执行；CPU 中的 profile 异常清理检查不能替代该资格。

## 实测结果

最后完整 CPU 测试为 **629 项通过，16.253 秒**。包括实际 CPU 线搜索内核、三种独立步长、非摩擦分支、回退、缓存归属、绑定互斥、异常恢复和显式身份测试。早期 627/628 项日志均保留。

每个 GPU 资格版本使用此前保存的同一批 **139,160 条**摩擦输入，实际生成的生产辅助函数在 RTX 5090 上执行；候选完整线搜索工厂也以 block32 在 CUDA 上编译，但没有在原生状态上执行。固定输入中 137,144 条同区间、2,016 条跨区间。没有积分、优化或归一化拟合。

| 版本 | 资格检查 | 梯度改变的输入行数 | Hessian 改变行数 | 单步长回退代价改变行数 | 三步长回退代价改变行数 |
|---|---:|---:|---:|---:|---:|
| V1 FP32 | 9/14，失败 | 1,194 | 0 | 821 | 263 |
| V2 FP64 代价 | 12/13，失败 | 0 | 0 | 669 | 0 |
| V3 FP64、直接回退 | 12/13，失败 | 0 | 0 | 669 | 0 |

表中三步长计数取每行相同 alpha 的首点；三个点的完整字节门槛均在报告中检查。V1 梯度最大绝对差 `1.1920928955078125e-7`。V2/V3 混合辅助函数测试中的单步长回退代价最大差 `4.76837158203125e-7`，2,016 条回退输入的代价负号判定没有改变。这些观察不能替代未通过的字节门槛。

V2/V3 候选代价相对固定输入 FP64 分段参考的绝对误差：中位 `2.899441953450345e-15`，p95 `1.125004045476885e-8`，最大 `7.446445735581619e-7`。原单步长最大误差 `2.088334025818206e-6`，原三步长最大误差 `2.8035897631228934e-6`。误差下降不等于后端合格，参考只是固定射线输入算术，不是动力学真值或任务成功证明。

V1 的 `derivative_matches_prior` 还比较了另一个历史探针程序的导数字节。V2/V3 将这一跨程序比较明确保留为观察项，而非配对保持门槛；相同旧公式在不同编译布局下本身即可不同。配对原版/候选导数和回退字节要求仍保留，V2/V3 仍因回退检查失败。没有重写早期报告或将失败重新标成成功。

## 独立复算与限制

新增保存数据复核 **24/24**，重新读取三版 NPZ，核对失败门槛、差异计数、输入/源码身份、同区间分类及零积分/更新。这个绿色结果仅证明失败证据完整，**不代表任何候选通过资格**。

额外四次独立原版/候选辅助内核执行仍观察到：单步长回退有 669 行不同、三步长回退有 763 行不同，导数/Hessian 均保持字节一致。混合测试中原单步长与原三步长本身也恰有 669 行回退代价不同，V3 候选单步长回退等于该布局下的原三步长输出。这支持继续调查浮点融合/编译布局，但还不能唯一确定编译器因果机制，也不能把混合测试的三步长字节一致推广到所有上下文。

原生比较 **尚未登记或消费**；v1.54 设想的 240 查询/1,920 积分仍只是未来计划。下一步先增加原版/恒等包装/稳定包装的中间量探针并检查生成 CUDA，分清绝对摩擦代价、相减和包装边界的舍入差异。必须取得可解释的保持契约与独立资格，再建立原生 W1 图/恢复对照；W32、Actor 拟合/训练、完整任务和真实 ego 结果仍不准入。不能仅为得到绿色结果放宽字节或物理门槛。
