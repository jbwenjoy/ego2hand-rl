# Research plan v1.66 — native multiclip training bridge

The original single-clip reset and the refitted clip 003 reset now run concurrently under one exclusive guarded W32 factory binding, with separate reference tables, physics, reset masks and CUDA graphs. The zero-update dual-runtime check verified state isolation and selective reset over 1,536 native integrations. One stochastic 64-control rollout at the same pretrained policy on each task produced 2,048 and 1,851 geometry-valid transitions out of 2,048 on clip 001 and clip 003 respectively. Clip 003 reached phase 60 under sampled actions. These are collection statistics, not deterministic policy success. [Runtime qualification](../runs/pen_two_clip_runtime_v1/report.json) · [collector validation](../runs/pen_multiclip_collectors_v1/report.json).

The old and refitted clip 003 hand and object starting qpos are identical. The new CPU LP reduced the minimum static normal-force sum from 6.97 N to 2.87 N and changed the initial servo target (and hence initial EMA and previous RAW feedback). On clip 003 the frozen residual Actor achieved zero valid windows with the old initialization versus one 20 ms window on all three new-initialization trials. Support valid prefixes were 1.00, 0.32 and 1.00 s vs 1.00 s in all three trials. Clip 002 with its new start gave 0.04 s residual and 0.16 s support, with zero full successes. [Evaluation](../runs/pen_dev_init_compare_v1/report.json).

In a separate crossed experiment only the first observed RAW history or only the physical servo initialization was switched. Either isolated change sufficed to pass one 20 ms control on clip 003 for the residual policy, and all such cases stopped in control two. Overriding only the first RAW input changed the residual Actor's mean action L2 by 0.036 and the applied PD target L2 by 0.009 rad. Switching physical initialization while keeping first observed RAW unchanged preserved the Actor output and changed the transmitted PD by 0.047 rad. This local threshold crossing is sensitive to both channels; it cannot be attributed solely to improved static force balance. [Factorial evidence](../runs/pen_dev_init_history_v1/report.json).

The shared-training pilot compares alternating on-policy residual PPO updates with one common policy against one separate policy per clip at equal total sampled transitions and update count. Results from both development clips must be reported; specialist performance on the other clip is transfer. Longer full-reference and independent-seed studies, shared-world-model A1/A2, reserved clips, realistic ego dynamics and hardware qualification remain open.
