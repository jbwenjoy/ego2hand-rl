# FlashSAC 终止后继的离线数值回归

取 R2 单序列训练第 548,352 步回放中的第 3,677 行。该行有有限的当前观察、动作、critic 上下文与折扣奖励项，标为真正终止且未超时。后继观察有 78 个非有限维度，后继 critic 上下文有 6 个非有限维度。测试使用第 456,960 步尚健康的 actor、critic、目标网络、温度及对应优化器，仅在 CPU 上做配对的单次优化器尝试。输入和输出均留在独立试验中。[原始问题与时间次序](hocap-single2-nonfinite-action.md)

## 局部规则与证据

对于已明确来自重置前状态、已完成 n 步聚合的回放行，真正终止会令原生 Bellman 目标的 bootstrap 权重为零。若只有后继观察或后继 critic 上下文失效，允许在送给 RL 网络的张量中，用该行的有效当前特征填充后继特征。保留实际动作、各项折扣奖励、终止与截断标志，并登记填充行号。此填充会改变坏行进入 BatchNorm 时的样本组成，只能作为数值策略。真实终止后的物理状态仍然未知。世界模型只允许从独立保留的原始、有限、单控制周期、重置前状态对中选择标签。本次数据是三步聚合，世界模型可用标签数为 0。

以 192 行有限的历史回放作小型存储，在已知会被相同采样密钥选中的一个槽位注入原始坏行。原生算法从中有放回抽取 128 行，实际抽到坏行 3 次。每个条件复用相同初始权重、Adam 状态、采样键、温度和奖励权重。

| 原生更新所见输入 | 非有限 learner 张量 / 191 | 非有限更新统计张量 | 结果 |
| --- | ---: | ---: | --- |
| 全有限对照 | 0 | 0 | 启用保护前后，完整学习器和日志张量逐位相同 |
| 原始坏终止行 | 33 | 4 | 数值提交检查拒绝候选，已有状态的哈希未变 |
| 对 1 个真实终止行使用 RL 填充 | 0 | 0 | BatchNorm、目标网络、温度及 Adam 状态有限 |

在归档的 FP16 损失缩放 4,194,304 下，带填充的更新改变了 actor 的 Adam 状态，原生梯度保护跳过了该次 critic 的 Adam 更新。仅为核验两个优化器都能运行，另在内存中把损失缩放设为 1,024，两个 Adam 状态都发生变化且全部数值有限。原生分类 Bellman 目标也作了独立检查。对同一真正终止行，改变有限的后继分布与熵，目标最大差约 3.0 × 10⁻⁸。对仍需 bootstrap 的对照，差约 0.30。[完整 CPU 回归与各叶检查](../runs/wuji_terminal_successor_guard_cpu_v3/report.json) · [保护逻辑](../src/supermimic_research/learning/terminal_successor_guard.py) · [可复算入口](../tools/regress_wuji_terminal_successor.py)

## 适用边界

以下 8 条用例逐一拒绝整个候选批次，涵盖非终止坏后继、仅超时的坏后继、终止与超时同时置位的坏后继、坏奖励分量、有限分量加权后奖励溢出，以及当前动作、观察或 critic 上下文本身失效。有有限后继的正常超时行仍按原生规则 bootstrap。原型也显式拒绝传入待聚合的 n 步队列、重置后或来源未知的后继，以及把三步回放当作一步物理监督的请求。

尚未验证实时场景发散后的状态恢复、并行 n 步队列按 world 隔离、无效后置状态进入下一次动作选择、或被污染旧检查点的修复。将来若接入在线训练，需要单独处理这些路径并计入发生次数。当前结果只说明一个实测传播路径能被隔离，不能据此重判已冻结的失败或推断新策略的轨迹成功率。
