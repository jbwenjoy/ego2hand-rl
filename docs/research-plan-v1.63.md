# Research plan v1.63 — substep motion and contact-switch sensitivity

On the same controlled single-clip pen task, fit eight pre-integration poses within each action window from the action-time state55, native warmstart26 and proposed held PD20. TRAIN_A and TRAIN_B own 20 source snapshots; all mixed directions are withheld from training, and TEST owns a separate policy. Its 200 branch packets span ten sources. The seven post-start instants in each packet are scored for pose and all eight instants for capacity. Independent CPU mesh queries use the same 72 BODY directions and the moving COM. These data have been inspected in previous experiments.

| Held-out mixed actions | Pen pose RMS (degrees) | Rotation response error / zero-response error | Capacity response error / zero-response error |
| --- | ---: | ---: | ---: |
| Direct absolute-pose network | 0.227 (all 200 branches) | 0.956 | 0.999 |
| Paired-supervision network | 0.442 (all 200 branches) | 1.001 | 1.001 |
| Post-hoc local secants | 0.257 (all 200 branches) | 0.189 | 0.921 |

The secant model uses 19 full-rank TRAIN anchors' measured pose responses and an absolute-pose network for nominal motion. Its rotation response points in a positive direction in all ten held-out mixed pairs. Native contact-geometry membership or multiplicity changed in one of those ten pairs. That case contributed 78.4% of squared capacity response; the secant model reproduced only 1.3% of its amplitude. With measured pen poses and predicted fingers, that case's capacity error ratio fell to 0.076. In a separate post-hoc factorial diagnostic with the actual hand path, replacing only the predicted object midpoint or only its differential with the measured value still gave roughly unit error. Raw pose accuracy, action sensitivity and realized contact transitions all matter near a switching surface.

Next prioritize a new policy-owned source bank that deliberately samples near contact onset or release, recording signed geometry gaps, body-relative velocities and changing surface pairs. Test whether predicting a switch and its timing on independent sources improves action ranking and whole-trajectory tracking before further imagined Actor updates. Retain the prior multi-reference, real ego dynamics and hardware objectives; these controlled substep studies alone do not establish transfer.
