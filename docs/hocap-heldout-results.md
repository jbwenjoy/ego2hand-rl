# HO-Cap 真实留出轨迹的 Wuji 重定向结果

在同一张 RTX 5090 上，三条逐条冷启动训练都达到了 418,560 个原生环境步。三条中一条学会了按演示把物体举起、搬运、放回和松手。按事前固定的全部指标，逐条方法为 **0/3**，主留出糖果盒为 0/1，两个补充样本为 0/2。原定的共享无模型策略、共享混合策略都在部署前查出非有限的归一化统计，两种最终策略在三个新目标上实际执行的动作数均为零。保留其全部预训练费用。另行登记了从同一训练谱系回退到数值正常检查点的补充比较。[冻结协议](hocap-heldout-comparison.md) · [主实验账本](../runs/wuji_heldout_formal_v1/cost_and_outcomes.json)

## 学会拿放的茶盒还差多少

## 支撑面带来的测量限制

茶盒在统一的水平桌面上复位时，盒底已经穿入桌面。四个逐条检查点在首个物理子步都测得 **10.11 mm** 盒桌穿透，超过 2 mm 门限，此时没有手盒载荷。独立静态场景在发出任何动作前就复现了这个间距。两台固定相机的深度估计也无法唯一确定一张同时符合首末盒底的桌面。原协议下的完整成功率包含这一固定场景误差，应同时报告实际搬运和其余门限。[初态零积分检查与深度残差](hocap-heldout-initial-support.md)

另在 CPU 上，对这两个走完全程的检查点重放各自所有已存低层指令。仅依照源首帧凸包最低点把水平桌面下移 10.23 mm，手和自由物体的源初态保持一致。两条指令仍能搬放茶盒，131 个区间均执行完毕，首子步穿透降至零。全段最大穿透从两组原桌面的 10.11 mm 分别降到 4.02 和 3.98 mm，仍超过 2 mm。对齐桌面后，两组位置与姿态 RMS 分别为 16.14 mm / 12.12° 和 25.43 mm / 10.11°。这是同一 CPU 引擎、同一指令的场景敏感性对照，计在正式算法比较之外。首帧盒底贴桌也未解决源首末支撑高度的一致性。[配对重放输入与结果](../runs/hocap_s5_support_control_replay_v1/comparison.json)
