# Multiclip update interference — frozen data and active native study

Both parent batches use 32 worlds × 64 controls and the same sampling-noise tensor. At the common parent, the full-batch Actor gradient cosine is −0.104. The paired four-world-block bootstrap spans −0.247 to +0.059. This single pair suggests slight opposition without establishing persistent antagonism. Weighted Critic gradient norms are 251.5 (001) and 1644.5 (003), versus Actor norms 10.82 and 14.28. The original joint clipping therefore rescales the gradients by 0.00397 and 0.000608 at this full-batch point. Actual PPO uses minibatches. [Gradient audit](../runs/pen_twoclip_parent_gradient_audit_v1/report.json).

Exact same-batch CPU updates with inherited Adam show material cross-clip action drift. A 32-step update on 001 produced KL 134.3 on the archived 003 observations. Resetting Adam and clipping Actor/Critic separately reduced that KL to 1.83. The effects interact; separate clipping alone need not help. Decaying the inherited first moment for 32 steps without new Actor gradients yielded KL near 0.05. [Counterfactuals](../runs/pen_single_update_interference_v2/report.json), [moment ablation](../runs/pen_first_moment_ablation_v1/report.json).

Two native ablations retain the common 2781 parent, frozen normalization, 65,536 new transitions and 1,024 actual Adam calls per profile. The partial-sharing profiles keep the shared Actor and private Critics; Actor Adam moments are shared or clip-specific. The balanced profiles keep shared Actor/Critic/Adam and collect both 64-control rollouts at the same policy before each update. Each minibatch then contains 128 transitions from each clip. Advantages are computed separately per source trajectory and normalized per clip. One balanced arm backtracks the Actor parameter step until reset-state and 32-sample mean analytic KL on each clip stay within 0.03 relative to the collector. Its Critic and both Adam moments continue updating. This is a bounded diagnostic on monitored observations, not a global KL guarantee.

In a CPU check on the same parent data the balanced first pair of rollouts produced reset-state KL 70.4 and 1164.8 after 64 ordinary Adam steps, versus 0.0120 and 0.0300 with the bound. The bounded Actor retained on average 4.46% of its proposed parameter step in this one update. Native sampling and tracking evidence are needed to assess usefulness. [CPU check](../runs/pen_balanced_cpu_check_v1/report.json).

The serial worker runs [partial sharing](../runs/pen_multiclip_partial_v1), balanced profiles and then W1 strict evaluation on both clips. The first partial-sharing checkpoint restored into two fresh environments. Estimated total wall time for this short protocol is several minutes, with additional time for independent evaluation and checkpoint I/O. Consult the run reports for terminal outcomes.
