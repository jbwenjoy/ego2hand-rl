# 显式路径梯度与共享表征：不能把已有收益全归于路径评分项

全部三组固定2000更新模型作只读分解，没有新训练、归一化拟合或原生查询。
同一网络的OBSERVABLE是原末状态/平均扳手评分，PATH_ONLY为预测区间几何
损失乘-.25，FULL为两者相加。保持实际PD输入、原RAW直接代价和控制器/
EMA链式关系；不把路径项当作硬碰撞/错误概率。

分析session61429正常exit0，73/73，9.913秒。FULL的全部行分数和源BASE的
RAW梯度与上一版保存数组逐字节相同。分解RAW相加最大差3.5763e-7、PD
偏导相加1.4305e-6，在登记的F32算术预算内；直接RAW路径项恒0。原生力/
扭矩/冲量物理门没有调整。独立保存算术审阅73/73，重算157116项，原1440
组、67个旧物理失败掩码、坏中心及两种native目标/稳定屏均保留。

开发验证10个已有源上，路径项梯度范数相对FULL的中位数和方向变化为：

比可到0.927、方向变化62.754°；不能把开发中位数推广为所有状态的界限。
范数比例也不是奖励收益归因比例。

PATH_POINT在去掉显式路径评分后，仍保留相对新基线的大部分稳定子集改善；
同网络加入路径项没有进一步明显改善这些指标。其OBS梯度相对基线网络的
整体L2变化约0.283，说明辅助训练改变了共享预测/表征。该固定种子结果
支持“训练表征作用很重要”的解释，不能证明跨种子通用因果关系，也不能
把这张表当作选择OBS模式的独立最终测试。

两个模式的全量原生FULL误差仍高，稳定子集的分析没有删除全量结果。此前
原生1500动作试验只回放过FULL方向，OBS方向可能相差数度；本轮没有新增
它的物理查询，不能把原来的单步收益重新记到未执行的OBS方向上。

裁剪后的实际RAW，不伪装旧探测/检查点schema或调用加载器。36个历史源
上下文检查通过，30个已有输入F32字节完全相同；6个原裁剪源保持声明，
没有新物理资格或训练样本。新增回归检查了warm、时钟、模式、相位、独立
缓冲区及裁剪语义；全549项测试通过。此项不等于新节点GPU保存/分支/
回退生命周期已验证。
