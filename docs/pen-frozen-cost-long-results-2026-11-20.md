# 转笔冻结策略长程评测

在一条 7.36 秒的受控参考上比较原版求解器和有条件稳定摩擦代价。三个策略各运行三次数值重复，共 18 例。每例使用全新 W1 runtime，只移植既有 Actor 和冻结的观测归一化。姿态来自仿真，两组均使用无物体外力辅助的设置。

| 策略 | 原版有效时长（秒） | 修复后有效时长（秒） | 停止原因 |
| --- | --- | --- | --- |
| 初始 | 0.20 / 0.20 / 0.20 | 0.20 / 0.20 / 0.20 | 两组均为位置误差 |
| 残差 | 2.32 / 1.34 / 1.32 | 3.48 / 3.48 / 3.50 | 原版三例均触发冲量审计，修复后三例均触发笔轴误差终止 |
| 支持 | 2.04 / 2.06 / 2.06 | 2.06 / 2.06 / 2.06 | 两组均为位置误差 |

完整任务成功 0/18。原版残差策略的第一段无效控制窗口分别在 2.34、1.36、1.34 秒结束，三个任务终止标志均未置位。两组残差策略的峰值线冲量残差为 3.0183e-6 和 7.9598e-9 N·s，门槛为 5e-7 N·s。原版未来在审计停止后缺失，因此无法用时长差估计原版的掉落时间或策略收益。

九组配对的初始 `qpos`、`qvel`、`time`、`ctrl`、`act`、mocap 和 warmstart 字节相同。四组完整 Data 数组相同，其余五组在 island 映射或接触编号数组上存在差异。共同有效比较窗口按策略分别为 0.20、1.32、2.04 秒。残差策略在 1.32 秒内 COM RMS 为原版 0.885–1.224 mm、修复后 0.883–0.888 mm。三次重复共用参考与策略，只能说明本次受控条件的行为。

V1 在首步之前因 MuJoCo 的长度 1 关节计数数组无法直接转为 Python 整数而退出，尝试和完成积分均为 0。V2 用 `.item()` 读取同一个计数，并用实际 MuJoCo 模型验证固定腕和重力补偿检查。V2 执行 11,616 次积分、1,452 个控制周期，独立 CPU 复核 21/21。观测及 RAW 的最大归一化 L2 误差分别约 1.03e-7、2.68e-7。优化和归一化拟合均为 0。646 项测试中 645 项通过、1 项按设计跳过 CUDA 分支。

两段三栏视频均取固定首重复，使用保存的 2.5 ms 原生姿态，20 倍慢放，停止后保持末帧。两段视频的解码首、中、尾帧均已查看。结果与文件哈希见 [证据账本](../provenance/pen_frozen_cost_long_v1/ledger.json)。
