# 持杯实验的源动作保真性更正

此前“完整重放两段 HOT3D 操杯参考”仅指重新锚定后的仿真参考。把这两条结果作为已修正人类端杯轨迹的证据，结论有误。旧参考去除了每帧源手腕运动，再将首帧杯体强制对齐到预选的机器人抓姿。还给每个指尖分别加入了机器人初始抓姿的偏置。杯子和手指相对这个新目标的跟踪误差不能替代相对源动作的误差。旧碰撞、力和稳定性记录仅作为固定抓姿的仿真对照保留。

以杯体 +Y 为杯底到杯口方向，在源世界 +Z 向上的约定下，001888 原标注帧杯口与向上方向约为 0.65–14.03°；旧仿真参考起点为 128.45°。该源轴约定尚无本采集序列的独立重力标定。新诊断给源手和杯子施加同一个、整段恒定的平移和绕竖直轴的旋转，使用原始时间戳。配准时首帧掌心位置重合，偏航由掌部标架确定。所有指尖采用源标注在杯体内的绝对位置。没有给手指分开平移，也没有把杯口逐帧强行拉直。

| 条件性固定腕诊断 | 001884 | 001888 |
|---|---:|---:|
| 新参考起始杯口倾角 | 1.77° | 13.36° |
| 源腕部相对起点最大位移 | 68 mm | 374 mm |
| 试算首帧五指尖 RMS | 70.3 mm | 58.5 mm |
| 试算首帧手部自穿透 | 12.6 mm | 2.81 mm |

这一固定基座、初始掌部配准和有界指尖 IK 组合在两个窗口中均未得到合格的起始抓姿，未执行动力学积分。因此修正参考已经生成，正向端杯的物理成功仍未建立。单次 IK 配准试算不能证明所有固定腕安装都不可行。完整动作验证应保留杯体相对于重力的姿态及源运动、对应指尖相对杯体的位置与接触阶段，再检验动力学。若裁剪为仅手内运动，应明确报告去除了哪些腕部平移/旋转，另列评价。
